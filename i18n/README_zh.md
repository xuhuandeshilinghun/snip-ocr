# SnapOCR
> High‑performance screenshot, desktop sticker and offline OCR utility built on C++17 / Qt6 for Windows platform.







SnapOCR 是面向 Windows 10 / 11 x64 平台的开源桌面一体化工具，集成高性能截图、桌面贴图悬浮预览、图片标注、多语言离线OCR识别、延时循环截图、自动更新全套能力。
**软件界面支持语言：中文、繁体、英文、日文、韩文、德文、法文、俄文；同时支持上述多语种OCR文字识别。**
全部图像与文字识别运算**在本地设备完成，不会将截图上传云端**，注重用户隐私。适合办公摘录资料、阅读翻译辅助、网页文档文字提取、程序员素材截取、教学演示截图标注等各类场景。
程序采用原生Windows API结合Qt6开发，支持高DPI多显示器环境，提供浅色/深色两套主题，完整的国际化多语言UI，常驻系统托盘后台运行。

## 功能特性
### 📷 截图模块
- **全局热键截图**：采用 Windows 低级键盘钩子 `WH_KEYBOARD_LL` 实现全局热键，无论当前窗口是否获得焦点，均可一键唤起截图。
- **自由区域选择**：鼠标拖拽划定选区，提供8个控制点自由缩放选区；同时支持键盘方向键微调选区位置，单步1px，Shift+方向键一次移动10px，精准选取像素区域。
- **窗口吸附对齐**：参考 Snipaste 的交互逻辑，选区边缘靠近窗口边界自动吸附，默认吸附阈值8px，快速完整选中整个窗口。
- **精准窗口与控件识别**：调用 `WindowFromPoint` + `RealChildWindowFromPoint`，可以识别按钮、输入框、工具栏等子控件，直接选中控件区域。
- **DWM真实窗口边界获取**：调用 `DwmGetWindowAttribute(DWMWA_EXTENDED_FRAME_BOUNDS)`，排除Windows窗口阴影，拿到窗口实际渲染尺寸。
- **像素放大镜**：截图模式下开启放大镜，实时展示鼠标位置RGB、HEX色值与屏幕坐标，支持颜色格式一键切换，适合取色、像素校对。
- **选区尺寸标签**：选区角落显示圆角蓝色背景的宽高标签 `W × H`，浅色/深色主题自动适配文字颜色。
- **截图操作工具栏**：完成框选截图之后底部弹出工具栏，支持贴图、OCR识别、二维码识别、复制图片、保存PNG文件、取消操作。

### 🖼️ 桌面贴图 & 标注
- **桌面悬浮贴图**：截图后可以直接把图片贴在桌面原位置，类似 Snipaste；完整支持DPR设备像素比，高分辨率屏幕下图片不会模糊失真。
- **全套绘图标注工具**：右键打开绘图工具栏，包含选择、画笔、箭头、矩形、椭圆、高亮、马赛克打码、文字注释、橡皮擦。
- **图片变换能力**：贴图支持20%‑500%区间缩放；支持90°顺时针/逆时针旋转、水平翻转、垂直翻转；全部操作基于原图物理分辨率，不会损失画质。
- **标注烘焙导出**：可以把所有绘制的标注烘焙合并到原图，输出完整的PNG图片，保留原始图像分辨率。
- **屏幕取色面板**：独立实现取色器面板，可以拾取屏幕任意位置颜色，适配多语言界面。
- **贴图窗口阴影**：可手动开关贴图窗口阴影，完美适配 Windows11 圆角窗口视觉风格。
- **贴图分组管理**：支持多套贴图分组（默认分组+自定义分组），切换分组会自动隐藏当前组贴图，恢复另一组全部贴图。
- **截图历史持久化**：截图原图以PNG格式保存至本地 `history` 目录；贴图位置、缩放、标注状态保存在 `.sp1` 文件，采用XOR+Base64做轻量混淆（非高强度加密，仅防止误修改）。
- **程序重启自动恢复贴图**：软件关闭再次打开，自动还原上一次所有悬浮贴图的位置、缩放与分组状态。

### 🔍 OCR 离线文字识别
- **多模型并行加载**：可同时载入多套识别模型，支持中日英混合、韩文、俄文西里尔字符、拉丁文体系文本识别。
- **语言自动判断模式**：算法分析图片字符占比，自动切换对应OCR模型，无需用户手动选择识别语言。
- **ONNX Runtime CPU推理**：完全依靠CPU运算，**不需要独立显卡**，普通笔记本也可以运行。
- **UI不阻塞后台线程**：OCR识别任务放到独立QThread工作线程执行，识别过程界面不会卡死。
- **识别结果弹窗**：OCR输出弹窗，文本支持编辑修改、一键复制剪贴板、保存为本地文本文件。

### ⏱️ 延时截图
- **延时循环截图**：支持设置1‑10秒延时，同时可以设定循环截图张数，自动批量保存图片。
- **系统Toast通知**：截图任务完成后，Windows右下角弹出系统通知，提示保存路径与截图数量，点击通知可快速复制存储路径。

### 🔄 自动更新系统
- **版本检测**：软件启动自动检测新版本，也可以在设置面板手动触发版本检查。
- **差分更新**：基于基准版本生成全量包与差分包，更新只下载改动文件，大幅降低下载体积。
- **双下载源路由**：国内用户自动跳转Gitee下载，海外用户使用GitHub Release，解决网络访问差异。
- **独立更新器程序**：`updater.exe` 使用原生Win32 API + minizip实现，不依赖Qt库。
- **配置与用户数据保留**：更新过程自动备份用户配置文件 `.config_settings.json`，更新完成恢复用户设置，不会丢失热键、主题、贴图分组配置。
- **更新重启逻辑**：更新完成调用 `ShellExecuteExW` 启动新版本，携带`--restart`参数跳过单实例互斥锁，正常完成重启。

### ⚙️ 系统集成
- **系统托盘常驻**：最小化到托盘，托盘右键菜单包含截图、OCR、延时截图、贴图分组、清空历史、首选项、重启程序、退出。
- **软件界面国际化**：内置简体中文 `zh_CN`、英文 `en_US` UI，运行时直接切换语言，Qt内置对话框同步本地化。
- **明暗主题自动适配**：跟随系统或者手动切换浅色/深色模式，遮罩、菜单分割线、窗口阴影全部适配主题。
- **单实例互斥锁**：使用全局Mutex防止程序重复多开；更新重启场景特殊参数跳过互斥锁限制。
- **中文路径兼容处理**：专门处理Windows UTF‑8中文路径，规避Qt原生API在中文路径下返回空值的bug。

## 下载与安装
1. 前往 [Releases](https://github.com/xuhuandeshilinghun/snip‑ocr/releases) 下载最新发行包：`SnapOCR‑<version>‑win64.zip`
2. 将压缩包完整解压到任意本地文件夹，绿色软件，无需安装程序。
3. OCR功能需要额外下载独立模型包，解压放置到程序目录下 `model/` 文件夹。
4. 直接运行 `SnapOCR.exe` 启动软件。

> **系统硬性要求：Windows10 / Windows11 x64**
> OCR模型文件体积较大，为缩减程序包体积，模型不会内置在主程序压缩包内。
> 不建议解压到系统保护目录，例如`C:\Windows`、`Program Files`，会产生权限读写问题。

| `F1` | 唤起截图模式 |

## 技术栈
- 开发语言：C++17
- GUI框架：Qt 6.5.3+
- 构建工具：CMake 3.20+ / MSVC
- OCR推理：ONNX Runtime 1.18.1 CPU
- 图像处理：OpenCV 4.x
- JSON解析：nlohmann/json
- Zip压缩解压：minizip
- Windows系统接口：Win32 API、DWM、低级键盘钩子
- 编译器：MSVC2019 / MSVC2022

## 隐私与安全说明
1. 截图、贴图处理、OCR文字识别全部在本机完成，软件**不会自动上传任何截图画面、识别文本至互联网**。
2. 自动更新功能会联网访问GitHub/Gitee服务器，仅用于版本校验与程序更新包下载。
3. `history`目录下截图原图以明文PNG存储；如果截取密码、证件等敏感信息，请手动及时清理历史文件夹。
4. `.sp1`、`index.dat`文件使用XOR+base64仅做简单混淆，**并非安全加密，不要用来保存高度敏感的资料**。
5. 软件可以在设置中关闭截图历史保存功能。

## 已知限制
- 当前仅支持 Windows 10/11 x64操作系统，暂不支持Linux、macOS平台。
- OCR为CPU运算，识别速度取决于电脑CPU性能。
- OCR模型体积较大，需要手动单独下载部署。
- 多显示器混合DPI缩放场景建议实际使用测试，部分特殊硬件环境可能存在适配问题。
