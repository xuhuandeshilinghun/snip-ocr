# SnapOCR
> 基於 C++17 / Qt6 建構，適用於 Windows 平台的高效能截圖、桌面貼圖與離線 OCR 工具。

SnapOCR 是面向 Windows 10 / 11 x64 平台的開源桌面整合工具，整合高效能截圖、桌面貼圖懸浮預覽、圖片標註、多語言離線OCR辨識、延遲循環截圖、自動更新完整功能。
**軟體介面支援語言：中文、繁體、英文、日文、韓文、德文、法文、俄文；同時支援上述多語言 OCR 文字辨識。**
所有圖像與文字辨識運算**皆在本機裝置完成，不會將截圖上傳至雲端，重視使用者隱私。**適合辦公資料摘錄、閱讀翻譯輔助、網頁文件文字擷取、程式素材截取、教學演示截圖標註等各種場景。
程式採用原生 Windows API 搭配 Qt6 開發，支援高 DPI 多螢幕環境，提供淺色/深色兩套主題，具備完整國際化多語言 UI，可常駐於系統列背景執行。

## 功能特性
### 📷 截圖模組
- **全域熱鍵截圖**：使用 Windows 低階鍵盤勾子 `WH_KEYBOARD_LL` 實作全域熱鍵，無論當前視窗是否取得焦點，都可以一鍵喚起截圖。
- **自由區域選取**：滑鼠拖曳劃定選區，提供 8 個控制點自由縮放選區；也支援鍵盤方向鍵微調選區位置，單步移動 1px，Shift+方向鍵一次移動 10px，精準選取像素區域。
- **視窗吸附對齊**：參考 Snipaste 的互動邏輯，選區邊緣靠近視窗邊界時會自動吸附，預設吸附閾值 8px，可快速完整選取整個視窗。
- **精準視窗與控制項辨識**：呼叫 `WindowFromPoint` + `RealChildWindowFromPoint`，可辨識按鈕、輸入框、工具列等子控制項，直接選取控制項區域。
- **DWM 真實視窗邊界取得**：呼叫 `DwmGetWindowAttribute(DWMWA_EXTENDED_FRAME_BOUNDS)`，排除 Windows 視窗陰影，取得視窗實際渲染尺寸。
- **像素放大鏡**：截圖模式可開啟放大鏡，即時顯示滑鼠位置的 RGB、HEX 色值與螢幕座標，支援一鍵切換顏色格式，適合取色、像素校對。
- **選區尺寸標籤**：選區角落顯示圓角藍色背景的寬高標籤 `W × H`，淺色/深色主題會自動調整文字顏色。
- **截圖操作工具列**：完成框選截圖後，底部彈出工具列，支援貼圖、OCR辨識、QRCode辨識、複製圖片、儲存PNG檔案、取消操作。

### 🖼️ 桌面貼圖 & 標註
- **桌面懸浮貼圖**：截圖後可以直接把圖片貼在桌面原本位置，類似 Snipaste；完整支援 DPR 裝置像素比，高解析度螢幕下圖片不會模糊失真。
- **完整繪圖標註工具**：右鍵開啟繪圖工具列，包含選取、畫筆、箭頭、矩形、橢圓、高亮、馬賽克打碼、文字註解、橡皮擦。
- **圖片變換功能**：貼圖支援 20%‑500% 縮放；支援 90°順時針/逆時針旋轉、水平翻轉、垂直翻轉；所有操作皆基於原始圖片物理解析度，不會損失畫質。
- **標註烘焙匯出**：可以把所有繪製的標註烘焙合併到原始圖片，匯出完整 PNG 圖檔，保留原始影像解析度。
- **螢幕取色面板**：獨立實作取色器面板，可以擷取螢幕任意位置顏色，相容多語言介面。
- **貼圖視窗陰影**：可以手動開關貼圖視窗陰影，完美搭配 Windows11 圓角視窗視覺風格。
- **貼圖分組管理**：支援多組貼圖分組（預設分組＋自訂分組），切換分組會自動隱藏目前分組貼圖，還原另一組全部貼圖。
- **截圖歷史持久儲存**：截圖原始圖片以 PNG 格式儲存於本機 `history` 目錄；貼圖位置、縮放、標註狀態儲存在 `.sp1` 檔案，使用 XOR+Base64 做輕量混淆（非高強度加密，僅防止誤改）。
- **程式重新啟動自動還原貼圖**：軟體關閉再次開啟，自動還上次所有懸浮貼圖的位置、縮放與分組狀態。

### 🔍 OCR 離線文字辨識
- **多模型平行載入**：可同時載入多套辨識模型，支援中日英混合、韓文、俄文西里爾字元、拉丁語系文字辨識。
- **語言自動判斷模式**：演算法分析圖片字元佔比，自動切換對應 OCR 模型，不需要手動選擇辨識語言。
- **ONNX Runtime CPU 推論**：完全依靠 CPU 運算，**不需要獨立顯卡**，一般筆記型電腦也可以執行。
- **UI 不阻塞背景執行緒**：OCR 辨識任務放置在獨立 QThread 工作執行緒執行，辨識過程介面不會卡死。
- **辨識結果彈窗**：OCR 輸出彈窗，文字可編輯修改、一鍵複製到剪貼簿、儲存為本機文字檔。

### ⏱️ 延遲截圖
- **延遲循環截圖**：可設定 1‑10 秒延遲，同時可以設定循環截圖張數，自動批次儲存圖片。
- **系統 Toast 通知**：截圖任務完成後，Windows 右下角彈出系統通知，提示儲存路徑與截圖數量，點擊通知可以快速複製儲存路徑。

### 🔄 自動更新系統
- **版本偵測**：軟體啟動自動檢查新版本，也可以在設定面板手動觸發版本檢查。
- **差異更新**：以基準版本產生完整安裝包與差異包，更新只下載變更的檔案，大幅減少下載體積。
- **雙下載來源路由**：中國大陸使用者自動導向 Gitee 下載，海外使用者使用 GitHub Release，解決網路存取差異問題。
- **獨立更新程式**：`updater.exe` 使用原生 Win32 API + minizip 實作，不依賴 Qt 函式庫。
- **設定與使用者資料保留**：更新過程自動備份使用者設定檔 `.config_settings.json`，更新完成還原使用者設定，不會遺失熱鍵、主題、貼圖分組設定。
- **更新重新啟動邏輯**：更新完成呼叫 `ShellExecuteExW` 啟動新版本，攜帶`--restart`參數跳過單一執行個體互斥鎖，正常完成重新啟動。

### ⚙️ 系統整合
- **系統列常駐**：最小化到系統列，系統列右鍵選單包含截圖、OCR、延遲截圖、貼圖分組、清空歷史、偏好設定、重新啟動程式、離開。
- **軟體介面國際化**：內建繁體中文、簡體中文 `zh_CN`、英文 `en_US` UI，執行階段直接切換語言，Qt 內建對話視窗同步在地化。
- **明暗主題自動適配**：跟隨系統或手動切換淺色/深色模式，遮罩、選單分隔線、視窗陰影全部適配主題。
- **單一執行個體互斥鎖**：使用全域 Mutex 防止程式重複開啟；更新重新啟動場景透過特殊參數跳過互斥鎖限制。
- **中文路徑相容處理**：專門處理 Windows UTF‑8 中文路徑，避開 Qt 原生 API 在中文路徑下回傳空值的問題。

## 下載與安裝
1. 前往 [Releases](https://github.com/xuhuandeshilinghun/snip‑ocr/releases) 下載最新發行包：`SnapOCR‑<version>‑win64.zip`
2. 把壓縮檔完整解壓縮到任意本機資料夾，綠色軟體，不需要安裝程式。
3. OCR 功能需要額外下載獨立模型包，解壓縮放置到程式目錄下的 `model/` 資料夾。
4. 直接執行 `SnapOCR.exe` 啟動軟體。

> **系統硬性需求：Windows10 / Windows11 x64**
> OCR 模型檔案體積較大，為縮減程式包大小，模型不會內建在主程式壓縮檔當中。
> 不建議解壓縮到系統保護目錄，例如`C:\Windows`、`Program Files`，會產生權限讀寫問題。

## 技術堆疊
- 開發語言：C++17
- GUI 框架：Qt 6.5.3+
- 建構工具：CMake 3.20+ / MSVC
- OCR 推論：ONNX Runtime 1.18.1 CPU
- 影像處理：OpenCV 4.x
- JSON 解析：nlohmann/json
- Zip 壓縮解壓縮：minizip
- Windows 系統介面：Win32 API、DWM、低階鍵盤勾子
- 編譯器：MSVC2019 / MSVC2022

## 隱私與安全說明
1. 截圖、貼圖處理、OCR 文字辨識全部在本機完成，軟體**不會自動上傳任何截圖畫面、辨識文字至網際網路。**
2. 自動更新功能會連線存取 GitHub/Gitee 伺服器，只用於版本驗證與程式更新包下載。
3. `history` 資料夾下截圖原始圖片以明碼 PNG 儲存；如果截取密碼、證件等敏感資訊，請手動即時清理歷史資料夾。
4. `.sp1`、`index.dat` 檔案使用 XOR+base64 僅做簡單混淆，**並非安全加密，不建議用來儲存高度敏感的資料。**
5. 軟體可以在設定中關閉截圖歷史儲存功能。

## 已知限制
- 目前僅支援 Windows 10/11 x64 作業系統，暫不支援 Linux、macOS 平台。
- OCR 為 CPU 運算，辨識速度取決於電腦 CPU 效能。
- OCR 模型體積龐大，需要手動單獨下載部署。
- 多螢幕混合 DPI 縮放場建議實際測試，部分特殊硬體環境可能會有相容問題。
